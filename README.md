# موقع Amvora - النسخة الكاملة (Next.js + قاعدة بيانات حقيقية)

موقع كامل بتقنية Next.js، متوافق تماماً مع SEO، مع لوحة تحكم حقيقية شاملة تتحكم فيها في كل حاجة في الموقع بدون لمس الكود.

## مميزات لوحة التحكم (`/admin`)
- **محتوى الموقع**: تعديل كل نصوص الهيرو، "من نحن"، ونادي VIP
- **الأقسام الثابتة**: تعديل كامل لأقسام "تشريح المنصات"، "ليه موقعك مهم"، "تخصصاتنا"، و"خطوات العمل" - **بالعربي والإنجليزي منفصلين**، أضف/عدّل/احذف أي عنصر في أي لغة، ولو ما عدّلتش حاجة، الموقع بيعرض محتوى احترافي جاهز تلقائياً في اللغتين
- **أعمالنا**: إضافة/تعديل/حذف/تثبيت مشروع كـ"مميز" في أول الصفحة
- **آراء العملاء**: إضافة/تعديل/حذف - والعملاء أنفسهم يقدروا يضيفوا رأيهم بتقييم نجوم من الموقع مباشرة، ويعدلوا/يحذفوا رأيهم بنفسهم من نفس المتصفح
- **الأسئلة الشائعة**: إضافة/تعديل/حذف سؤال وإجابته - **بالعربي والإنجليزي منفصلين**
- **صور الغلاف**: صور متعددة تتناوب تلقائياً خلف قسم الهيرو
- **الإعدادات**: رقم الواتساب، إيميل التواصل، الأسعار، روابط فيسبوك/إنستجرام/لينكد إن، معرف Google Analytics، نص الشريط المتحرك أعلى الموقع
- **الأمان**: تغيير كلمة سر لوحة التحكم من داخل اللوحة نفسها

## الخطوات بالترتيب

### 1. ارفع المشروع على GitHub
### 2. اربط المشروع بـ Vercel
### 3. اربط قاعدة بيانات Postgres
من تبويب Storage في Vercel → Create Database → Postgres (Neon) → اربطها بالمشروع.

### 3ب. اربط تخزين الصور (Vercel Blob) - عشان ترفع صور من جهازك مباشرة
من نفس تبويب Storage → Create Database → **Blob** → اربطها بالمشروع (هيضيف `BLOB_READ_WRITE_TOKEN` تلقائياً). من غيرها، لسه تقدر تحط رابط صورة يدوي، بس مش هترفع من جهازك مباشرة.

### 4. جهّز كلمة سر أولى للوحة التحكم (تقدر تغيرها لاحقاً من داخل اللوحة)
```
node scripts/hash-password.mjs "اكتب-هنا-كلمة-السر-الأولى"
```

### 5. أضف متغيرات البيئة في Vercel (Settings → Environment Variables)

| الاسم | القيمة |
|---|---|
| `ADMIN_USERNAME` | اسم دخول تختاره |
| `ADMIN_PASSWORD_HASH` | ناتج الخطوة 4 (تُستخدم أول مرة فقط، بعدها تقدر تغيرها من اللوحة) |
| `SESSION_SECRET` | نص عشوائي طويل (32 حرف فأكتر) |
| `NEXT_PUBLIC_SITE_URL` | رابط موقعك |

بعدها اعمل **Redeploy**.

### 6. جهّز جداول قاعدة البيانات (مرة واحدة)
```
npm install
npm run db:init
```

### 7. جرب لوحة التحكم على `yourdomain.com/admin`

### 8. اربط الدومين بتاعك لما تجيبه
Vercel → Settings → Domains، وحدّث `NEXT_PUBLIC_SITE_URL`.

## تفعيل Google Analytics (تتبع الزوار والإعلانات)
1. اعمل حساب على analytics.google.com
2. جهّز "Data Stream" لموقعك، وهياديك معرف شكله `G-XXXXXXX`
3. حطه في لوحة التحكم → الإعدادات → التتبع والإعلانات
4. من غير أي تعديل تاني في الكود، التتبع هيشتغل تلقائياً

## تحسين الظهور في جوجل (SEO)
- الموقع بيولّد `sitemap.xml` و`robots.txt` تلقائياً
- بعد ربط الدومين، سجّل الموقع في **Google Search Console** (search.google.com/search-console) → إضافة ملكية → اختار طريقة "HTML tag" → انسخ القيمة اللي جوه `content="..."` بس، وحطها في لوحة التحكم → الإعدادات → "كود تحقق Google Search Console" → احفظ، وبعدين ارجع لـ Search Console ودوس "تحقق"
- أضف رابط الـ sitemap في Search Console: `yourdomain.com/sitemap.xml`

## زرار الترجمة للإنجليزية
فوق الموقع فيه زرار لغة بيسمح للزائر يترجم الموقع بالكامل للإنجليزية أوتوماتيك عن طريق Google Translate. **مهم توضيحه بصراحة:** دي ترجمة آلية فورية (زي ترجمة جوجل العادية)، مش ترجمة احترافية بشرية - ممكن تكون دقيقة 90% بس مش مثالية 100% في كل التعبيرات التسويقية. لو حبيت ترجمة احترافية حقيقية للإنجليزية بعدين، تقدر تطلب مني أكتب نسخة إنجليزية كاملة من كل النصوص.

## صفحة سياسة الخصوصية
موجودة على `yourdomain.com/privacy` ومربوطة في الفوتر، بتوضح للزوار إزاي بتتعامل مع بياناتهم (الاسم، الهاتف، الآراء).

## ملاحظات مهمة وصادقة

- **الأسعار** حالياً Placeholder - غيّرها من لوحة التحكم بأول أرقام حقيقية.

- لو حصلت مشكلة في أي خطوة، ابعتلي رسالة الخطأ وأنا أساعدك تحلها.
